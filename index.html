magx

magx is a personal command-line tool that manages AI coding agent sessions (Claude Code and Codex) in tmux and keeps a local, searchable index of their work.

magx can read Google Docs and Google Sheets that its owner links in agent sessions. It exports them through the Google Drive API to local snapshots, so the documents can be previewed and searched offline. Everything runs on the owner's own computer.

magx is not a public service: it is used only by its author and is not offered to other users.
